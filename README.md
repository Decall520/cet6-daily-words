# 六级 · 每日十词

一个无需安装、打开即用的六级英语单词网站。每天按日期自动生成 10 个单词，单词包含音标、多个中文义项和两条双语例句。

## 使用方法

直接双击 `index.html` 即可使用。所有功能和词库都在本地，不需要联网。

也可以在项目目录启动一个简单的本地服务器：

```powershell
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 功能

- 每天自动展示 10 个六级高频词，同一天刷新顺序不变。
- 点击圆形勾选按钮或底部按钮，标记单词为已掌握。
- 自动保存当天进度与连续打卡天数。
- 完成今日任务后，可点击“提前背 10 个”继续加练下一组单词。
- 支持点击“发音”调用浏览器英文朗读。
- 自动适配电脑和手机，并支持深色模式。

## 自定义词库

词库位于 `data/words.js`。每个单词使用以下结构：

```js
["example", "/ɪɡˈzɑːmpl/",
  [["n.", "例子；实例"], ["v.", "举例说明"]],
  [["This is a good example.", "这是一个好例子。"],
   ["She exemplified the problem.", "她举例说明了这个问题。"]]
]
```

增加或修改词条后刷新网页即可生效。当前内置 100 个单词，系统会每 10 天循环使用一轮，并在新轮次中重新排序。

## 数据说明

学习进度存储在浏览器的 `localStorage` 中，不会上传到服务器。清除浏览器网站数据会同时清除进度。
